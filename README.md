# Exploratory Data Analysis (EDA) of Bank Historical Stock Data

## Overview

This project delivers a comprehensive **Exploratory Data Analysis (EDA)** of historical banking sector stock prices using **Python-based data analytics and visualization techniques**. The analysis leverages publicly available financial data sourced from **Yahoo Finance** to examine trends, volatility, correlations, and sector performance from the **2008 financial crisis through early 2020**.

The project demonstrates end-to-end proficiency in **data collection, preprocessing, exploratory analysis, visualization, and dashboard development**, making it suitable for data analyst, data scientist, and financial analyst portfolios.

---

## Objectives

- Analyze long-term trends and volatility in bank stock prices  
- Identify sector-wide patterns and correlations across major banks  
- Visualize financial time-series data for actionable insights  
- Build an interactive dashboard for stakeholder-friendly exploration  

---

## Tech Stack & Tools

- **Programming Language:** Python  
- **Data Analysis:** pandas, NumPy  
- **Data Visualization:** matplotlib, seaborn  
- **Data Source:** Yahoo Finance  
- **Dashboarding:** Tableau  
- **Environment:** Jupyter Notebook

## Project Workflow

1. **Data Acquisition**  
   - Retrieved historical stock price data from Yahoo Finance using Python APIs  

2. **Data Preprocessing**  
   - Handled missing and inconsistent values  
   - Transformed raw price data into analysis-ready formats  
   - Engineered features such as returns, moving averages, and volatility metrics  

3. **Exploratory Analysis & Visualization**  
   - Time-series trend analysis using line plots  
   - Volatility and return distribution analysis  
   - Correlation analysis using heatmaps  
   - Comparative analysis across multiple banks  

4. **Dashboard Development**  
   - Designed an interactive Tableau dashboard  
   - Enabled filtering and comparative analysis  
   - Translated analytical findings into business-focused visuals  

---

## Repository Structure

- **Data Preprocessing Scripts**  
  Python scripts and notebooks for data cleaning, transformation, and feature engineering  

- **Visualization Notebooks**

- **Tableau Dashboard**  
  Tableau workbook (`.twb`) and supporting data extracts for interactive exploration

## Results & Insights

- Identified significant volatility spikes during the 2008 financial crisis  
- Observed recovery and long-term growth trends across major banking stocks  
- Highlighted strong correlations between bank stocks during market stress periods
